# Cursor

The Cursor plugin bundles the Sphinx skill and MCP configuration for use in Cursor.

## Individual Installation

Install Sphinx from the [Cursor Marketplace](https://cursor.com/marketplace) when available, or add this repository as a plugin source following Cursor's plugin documentation.

References:

- [Cursor plugins](https://cursor.com/docs/reference/plugins)
- [Cursor marketplace](https://cursor.com/marketplace)

## Team Installation

Team and Enterprise admins can distribute Sphinx through a private team marketplace. Use the [Cursor dashboard](https://cursor.com/dashboard) to manage team settings, and publish this repository's `.cursor-plugin/marketplace.json` as the marketplace manifest.

References:

- [Cursor plugin marketplace manifest format](https://cursor.com/docs/reference/plugins#marketplace-manifest-format)
- [Cursor team dashboard](https://docs.cursor.com/account/teams/dashboard)
- [Cursor Teams](https://cursor.com/en-US/business/teams)
